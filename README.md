This is a Reciepe Saver MERN stack website. Its functions are the abillity to make your own reciepes, choose from a preset of reciepes, and updating your reciepes by removing them. It Interacts with 2
Mongo schemas, one being for the preset reciepes and the other is the user reciepies tha the user can add and remove.
