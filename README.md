This is a Recipe Saver MERN stack website. Its functions are the abillity to make your own recipes, choose from a preset of recipes, and updating your recipes by removing them. It Interacts with 2 Mongo schemas, one being for the preset recipes and the other is the user recipies tha the user can add and remove. This project is not a deployment, it can only run locally on your computer.

To run it after downloading it in VsCode: open project file, path to the backend using cd, npm install in terminal, path to the front end, npm install in terminal. Then after installing the node and react for the project run it by node server.js in the backend and npm start in the frontend.
